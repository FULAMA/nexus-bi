# nexus-bi

Analyse des données — Nexus BI (Remix)

Description

Ce projet fournit des outils et des pipelines pour l'analyse de données, transformation ETL et tableaux de bord.

Installation

1. Cloner le dépôt: git clone https://github.com/FULAMA/nexus-bi
2. Importer dans votre IDE ou builder Gradle

Usage

- Voir le dossier `app/` pour l'application principale.
- Exécuter les scripts ETL depuis le répertoire `app` selon la configuration Gradle.

Captures d'écran

Ajoutez des captures d'écran dans `app/src/main/res/drawable/` ou créez `docs/screenshots/` et liez-les ici. Exemple de bonnes pratiques:

- écran d'accueil: `docs/screenshots/home.png`
- rapport: `docs/screenshots/report.png`

Icône adaptive (recommendé)

L'application utilise une icône adaptive. Remplacez `app/src/main/res/drawable/ic_app_logo.jpg` par un SVG vectoriel pour de meilleurs résultats sur toutes tailles d'écran. Pour générer des icônes adaptatives:

1. Ouvrir Android Studio > Image Asset > Launcher Icons (Adaptive and Legacy)
2. Importer le SVG, définir le fond (couleur `@color/primary`) et générer

Contribuer

Contributions bienvenues via PR. Respectez les standards de code et ajoutez des tests pour toute nouvelle fonctionnalité.
