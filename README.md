# nexus-bi

Analyse des données — Nexus BI (Remix)

Description

Ce projet fournit des outils et des pipelines pour l'analyse de données, transformation ETL et tableaux de bord.

Installation

1. Cloner le dépôt: git clone https://github.com/FULAMA/nexus-bi
2. Importer dans votre IDE ou builder Gradle

Usage

- Voir le dossier `app/` pour l'application principale.
- Exécuter les scripts ETL depuis le répertoire `app` selon la configuration Gradle.

Contribuer

Contributions bienvenues via PR. Respectez les standards de code et ajoutez des tests pour toute nouvelle fonctionnalité.
